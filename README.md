# XA_Link

Keep the links you use on a desktop of your own, sorted into folders you arrange yourself.

• Double click XA_Link.exe to start
• New Folder makes a folder, double click one to open it
• Add Link saves a link inside it
• Double click a tile to open the link in your browser
• Drag tiles to arrange them
• Right click a tile or folder to edit, recolour or delete it
• Search looks through every folder at once
